# Cloudflare R2 media setup

The application stores only public media URLs in Supabase. Images and videos are uploaded directly from the administrator's browser to Cloudflare R2 through a five-minute, single-file upload URL generated by Vercel. R2 credentials remain server-only.

## 1. Create and publish the bucket

1. In Cloudflare, create an R2 bucket named `estateflow-media`.
2. In the bucket **Settings**, add a custom domain such as `media.example.com` and wait until it is active.
3. Do not use the `r2.dev` URL in production.
4. Create an R2 API token restricted to this bucket with **Object Read & Write** permissions. Keep its access key and secret private.

## 2. Configure browser uploads

In the R2 bucket **Settings → CORS policy**, save this policy. Replace the example domains with the exact production and Vercel preview origins you use.

```json
[
  {
    "AllowedOrigins": [
      "http://localhost:3000",
      "https://your-project.vercel.app",
      "https://www.example.com"
    ],
    "AllowedMethods": ["PUT"],
    "AllowedHeaders": ["Content-Type"],
    "MaxAgeSeconds": 3600
  }
]
```

## 3. Add Vercel environment variables

Add the following to the Vercel project for Production, Preview, and Development as appropriate. The first four are secrets: never prefix them with `NEXT_PUBLIC_` and never put them in browser code.

```env
R2_ACCESS_KEY_ID=your-r2-access-key-id
R2_SECRET_ACCESS_KEY=your-r2-secret-access-key
R2_BUCKET_NAME=estateflow-media
R2_ENDPOINT=https://your-cloudflare-account-id.r2.cloudflarestorage.com
NEXT_PUBLIC_R2_PUBLIC_URL=https://media.example.com
```

Add the same values to the local `.env.local` file to test uploads locally. Restart the development server after changing environment variables.

## 4. Apply the database change

Run [`app/supabase/r2-media.sql`](app/supabase/r2-media.sql) in Supabase SQL Editor. It adds `video_url` to property records.

## Using media in the dashboard

Under **Admin → Manage properties**, use the upload buttons beside the main image, gallery, and video fields. Upload first, then save the property. Images accept AVIF, JPEG, PNG, and WebP up to 20 MB. Videos accept MP4, MOV, and WebM up to 4 GB; upload MP4/H.264 where possible for the broadest browser compatibility.

The direct upload is intentionally not resumable. For exceptionally large walkthroughs or adaptive streaming, use Cloudflare Stream instead of a single R2 file.
